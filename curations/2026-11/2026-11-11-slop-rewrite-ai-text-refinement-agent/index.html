3단계 기준 기반의 자연스러운 재작성#

slop-rewrite 는 기계적인 규칙 검색에만 의존하지 않습니다. 코드 단계에서는 수정이 필요한 지점만 지정하고 실제 재작성은 LLM에 맡깁니다. 글의 전체 흐름을 유지하면서 자연스럽게 문장을 다듬습니다.

이 에이전트는 글을 다듬을 때 3가지 기준을 순차적으로 적용합니다.

  1. 공통 AIT 제거 규칙을 적용해 어색한 비유와 상투적인 표현을 정제합니다.
  2. 사용자 문체 가이드를 불러와 작성 목적에 맞는 어조를 설정합니다.
  3. 아티팩트 댓글이나 피드백으로 축적된 개인 취향을 반영합니다.

기본 내장된 스타일 외에도 내장 스킬인 Style Guide Builder를 쓰면 뉴스레터나 기존 작성 글을 학습해 전용 스타일을 만듭니다. 취향이 쌓일수록 사용자 의도에 정확히 부합합니다.

저장소 클론과 전역 스킬 등록#

에이전트는 GitHub 저장소로 공개되어 있습니다. Claude Code나 Codex 같은 CLI 환경에서 바로 받아 쓸 수 있습니다.

원하는 작업 폴더에서 저장소를 클론한 뒤 User scope 스킬로 등록합니다. 전역 스킬로 등록해야 어떤 프로젝트 폴더에서든 윤문 명령을 내립니다. 블로그 초안이나 개조식 보고서를 다듬을 때 스킬 이름을 호출하면 즉시 윤문본을 보여줍니다.

에이전트를 고도화하는 피드백 방식#

에이전트 성능을 끌어올릴 때는 귀납적 방식과 연역적 방식을 함께 활용합니다.

귀납적 개선은 작성했던 기존 결과물이나 댓글 첨삭을 제공해 작업 기준을 역추론하도록 만드는 과정입니다. AI 결과물에 댓글을 달아 구체적인 피드백을 남기면 에이전트가 자신만의 수정 기준을 스스로 만듭니다.

연역적 개선은 작업 절차를 시각화한 뒤 구조적 아이디어를 보태는 방식입니다. 세부적인 단계마다 개입하기보다는 전체 흐름을 확인하고 특정 단계의 주체를 조정하는 정도가 적당합니다. AI 에이전트에 세세한 지시를 내리기보다 목표와 기준을 명확히 제시하는 접근이 좋은 결과를 만듭니다.

  • slop-rewrite는 기계적 단어 치환이 아닌 LLM 기반 재작성을 통해 글의 흐름과 맛을 살려줍니다.
  • 공통 AIT 규칙, 문체 가이드, 개인 피드백 취향이라는 3단계 기준을 적용해 사용자 맞춤형 윤문이 가능합니다.
  • 에이전트 성능은 세부 절차 통제보다 귀납적 피드백 제공과 목표 중심의 최소 개입으로 끌어올릴 수 있습니다.
